# 🎹 Open Survivor (오픈 서바이버)

사용자가 직접 게임의 외형을 커스터마이징하고, 끊임없이 몰려오는 적들로부터 살아남는 **웹 기반 로그라이크 서바이벌 게임**입니다.

## 🚀 주요 특징 (Key Features)

*   **실시간 스킨 커스터마이징:** 게임 중 언제든지 플레이어와 적의 이미지를 업로드하여 바꿀 수 있습니다. 업로드된 이미지는 자동으로 깔끔한 **원형 크롭** 처리가 되어 게임 규격에 맞춰 적용됩니다.
*   **3종 무기 & 진화 시스템:**
    *   **자동 소총 → 레일건:** 가장 가까운 적을 자동 조준하여 사격합니다. 연사 강화(속도 15%↑)와 화력 상향(공격력 +5) 업그레이드 가능. 화력 2회 + 연사 5회 이상 완료하면 **레일건**으로 진화하여 탄환 속도 증가 및 최대 3회 관통.
    *   **에너지 블레이드 → 플라즈마 블레이드:** 플레이어 주변을 공전하며 다가오는 적들을 베어 넘깁니다. 최대 6개까지 추가 가능. 6개 보유 + 낙뢰 3개 이상일 때 **플라즈마 블레이드**로 진화하여 타격 시 연쇄 라이트닝 추가.
    *   **낙뢰 → 스톰 콜러:** 무작위 적에게 강력한 낙뢰를 떨어뜨립니다. 5개 이상 보유 + 자석 레벨 2 이상일 때 **스톰 콜러**로 진화하여 쿨다운 감소 및 주변 적 연쇄 타격.
*   **로그라이크 성장 시스템:** 레벨업 시 3가지 무작위 강화 카드 중 하나를 선택하여 나만의 빌드를 구성할 수 있습니다.
*   **3종 보스 시스템:**
    *   **광전사 (Berserker):** 플레이어 방향으로 돌진하는 패턴 보유. 돌진 전 경고선과 예상 지점을 표시한 후 고정된 방향으로 돌진합니다.
    *   **포격자 (Artillery):** 레이저와 탄막 공격을 사용. 레이저는 예고선이 플레이어를 추적하다가 발사 직전 방향이 고정되어 회피가 가능합니다.
    *   **소환사 (Summoner):** 미니언을 소환하고 광역 폭발 공격을 사용합니다.
*   **자석 & 등급 보석 시스템:**
    *   경험치 보석 근처에 가면 자석처럼 보석이 플레이어에게 빨려 들어옵니다. (초기 범위 140px)
    *   보석 등급(Cyan, Green, Purple, Gold)에 따라 획득하는 경험치 양이 다릅니다.
*   **지능형 난이도 조절:** 시간이 경과함에 따라 적들의 스폰 속도와 체력, 이동 속도가 점진적으로 상승하며, 특정 시간대별로 밸런스가 정밀하게 조정되어 있습니다.
*   **유한 월드 래핑 시스템:** 4000×4000 크기의 월드를 경계에서 반대편으로 이어지도록 구현하여 끊김 없는 탐색을 제공합니다. 적, 투사체, 보석 모두 월드 경계에서 래핑됩니다.
*   **체력 회복 드랍:** 업그레이드 카드의 긴급 복구를 제거하고, 적 처치 시 낮은 확률로 십자 모양의 체력 회복 아이템(+20 HP)이 드랍됩니다. (일반 1%, 엘리트 3%, 미니보스 7%, 보스 12%)

## 🎮 조작 방법 (How to Play)

*   **이동:** `W`, `A`, `S`, `D` 또는 **방향키**
*   **공격:** 자동 조준 및 자동 발사 (무기 획득 시)
*   **강화:** 경험치 바를 채워 레벨업 시 나타나는 선택지 중 하나를 클릭
*   **일시정지:** 우측 하단 `||` 버튼 클릭으로 게임 중지 및 재개
*   **관리자 콘솔:** 우측 상단 레벨(Lv) 텍스트 클릭 시 테스트용 메뉴 오픈

## 🛠️ 기술 스택 (Tech Stack)

*   **Engine:** Phaser 3 (JavaScript Game Engine)
*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
*   **Deployment:** Vercel
*   **Version Control:** GitHub

    *   레일건 진화 조건: 화력 3회+연사 3회 → 화력 2회+연사 5회.

    *   모든 업그레이드 가중치 1로 통일 (동등 확률).
    *   플레이어 이동 속도 280 → 310, 러너 최대 속도 312로 제한.

    *   레일건 관통이 동일 적 중복 타격하는 문제 수정 (hitEnemies Set 도입).
